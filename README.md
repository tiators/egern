# 彩云天气小组件安装教程

请使用支持通用脚本和小组件的 Egern 版本；找不到对应入口时，先更新 Egern。

## 1. 添加脚本

1. 打开 Egern，进入 **工具 → 脚本 → +**。
2. 按下表填写：

   | 项目 | 内容 |
   | --- | --- |
   | 名称 | `caiyun-weather` |
   | 类型 | `generic / 通用` |
   | 文件位置 | 本地 |
   | 文件名 | `weather-widget.js` |
   | 超时 | 30 秒 |

3. 打开仓库中的 [weather-widget.js](scripts/weather-widget.js)，复制全部代码。
4. 在 Egern 中点击 **编辑文件**，粘贴代码并保存。

## 2. 设置地区

在脚本的 **Env / 环境变量** 中添加：

| 名称 | 填写内容 |
| --- | --- |
| `REGION` | 必填完整市区名，例如 `杭州市西湖区`，无需加引号 |
| `TITLE` | 可选，自定义显示名称；留空使用地区名称 |
| `REFRESH_MINUTES` | 可选，填写 `15`、`30` 或 `60`；默认 30 分钟 |

保存设置。同名区请带上城市名。

## 3. 创建小组件

1. 进入 **分析**，点击左上角按钮打开 **小组件画廊**。
2. 点击 **+**，名称填写“彩云天气”，脚本选择 `caiyun-weather`。
3. 保存，确认画廊中显示的地区和天气正确。

## 4. 添加到主屏幕

1. 长按 iPhone 主屏幕空白处，选择 **编辑 → 添加小组件**。
2. 搜索 **Egern**，选择小、中或大尺寸并添加。
3. 长按刚添加的小组件，选择 **编辑小组件**，将小组件名称设为“彩云天气”。

需要多个尺寸时，重复添加并选择同一个“彩云天气”即可。
