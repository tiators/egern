# Weather Widget Installation

1. Open Egern → **Tools → Modules → +**, add this URL and save:

   [Module URL](https://raw.githubusercontent.com/tiators/egern/refs/heads/main/modules/weather-widget.yaml)

2. Set `REGION` in the module settings to the full city and district name, for example `杭州市西湖区`, then save and enable the module. English queries can match an unrelated business entry instead of the district.
3. Add an **Egern** widget to your iPhone Home Screen. Choose a size, then long-press → **Edit Widget** → select **Weather**.
